## 运营节奏（每日执行清单）

1. 每天 2–3 条（不同剧、不同语言号轮换）
2. 发布时间（目标市场黄金时段）：印尼 19–22 点（GMT+7）、泰国同、越南同
3. 评论区置顶：当地语言一句话 + "完整版 YT688"
4. 违规红线：不要直接贴链接在视频里（用主页 bio + 评论区），避免限流
5. 数据复盘：播放 >1 万的视频追加同款剪辑；低于 2000 的换剪辑点重发
