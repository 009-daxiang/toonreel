📖 Installation Guide

🤖 Android
  1. Tap “Download APK” in the card above.
  2. When your phone asks, allow “Install unknown apps” for your browser.
  3. Open the downloaded file and tap Install.
  4. ToonReel appears on your home screen — tap to watch.

Can’t install? Make sure no other download is running, then try again. The APK is safe — it only loads the official ToonReel site.

🍎 iPhone / iPad
  1. Open toonreel in Safari
  2. Tap the Share button
  3. Choose “Add to Home Screen”
  4. Tap Add — the ToonReel icon appears on your home screen. Open it for the full-screen app.

Use Safari for these steps — other browsers don’t support home-screen apps on iOS.

💻 Mac
  1. Click “Download for Mac” in the card above.
  2. Unzip the downloaded file.
  3. Drag ToonReel.app into your Applications folder.
  4. First launch: right-click the app → Open (one-time confirmation for unsigned apps).

Requires macOS 11+ on Apple Silicon. Intel Macs: use the browser “Install” option instead.

🪟 Windows
  1. Open the ToonReel site in Chrome or Edge.
  2. Click the install icon in the address bar (or menu ⋯ → Apps → Install this site as an app).
  3. Confirm Install — ToonReel opens in its own window and gets its own Start-menu icon.

Don’t see the install icon? You’re likely already running the installed app — enjoy!
